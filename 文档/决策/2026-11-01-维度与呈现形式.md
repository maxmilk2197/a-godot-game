# 维度与呈现形式 — 决策记录

日期：2026-11-01
项目：眠冬与你（D:\sister）

## 决策

| 决策 | 选择 | 为什么 | 何时复审 |
|---|---|---|---|
| 维度 | **2D 俯视（top-down）** | 已有 Pixel Art Top Down 像素素材；零 3D 资产；移动端包体与发热代价小。俯视 2D 同样能给「走动」的空间感 | 3D 美术产能真正落实、或俯视 2D 的沉浸感被证明不够时 |
| 走动空间范围 | **仅屋外可走；家保持界面式** | 家承担对话与养成，界面式效率更高；走动感由屋外承担。家的 51 节点不动，改造风险最低 | 室内走动成为明确需求时 |
| 场景层 / UI 层边界 | **走动层独立成 `Node2D` 场景层，UI 走 `CanvasLayer` 叠其上** | 把 3D 化的不可逆点压到最低：将来换 3D 只替换场景层，手机/电脑/对话/养成整套不动 | 真正切换到 3D 时（届时只重写场景层） |
| 当前阶段目标 | **搭 2D 俯视走动底座**：移动、碰撞、交互触发、镜头跟随 | 先让「能走动」这件事真实存在，再谈内容 | 底座跑通后转入第一章内容 |
| 美术前提 | **占位优先**，底座不依赖美术资产 | 3D 产能未定，像素风格也未定调；用色块/简单瓦片即可验证手感 | 走美术定调阶段时 |

## 依据（调研事实）

- 渲染器：`mobile`
- 3D 节点：共 3 个，全部位于 `场景/主菜单/背景.tscn`（Node3D + WorldEnvironment + Camera3D），为装饰性天空，非玩法
- 3D 模型资源：0（无 glb/gltf/fbx/obj/blend）
- 2D 主结构：TextureRect 35 · Sprite2D 18 · Node2D 9 · TileMapLayer 1 · AnimatedSprite2D 1
- 场景 21 个，全部 UI / 2D 驱动
- 核心玩法：Dialogic 对话 · 养成数值（时段/心情/好感/体力）· 手机与电脑界面模拟 · 便利店商店
- 目标平台：Mobile（安卓已产出 67 MB 包）
- `场景/屋外/世界.tscn` 现状：`Node2D` + `TileMapLayer` + `CanvasLayer`（回家 / 便利店两个按钮），共 5 节点 —— 结构方向已正确，只是内容占位

## Open / deferred

- **3D 美术产能** —— 未定（用户答「不知道」）。**不阻塞当前阶段**：场景层已隔离，随时可换。
- **出门场景的正式内容**（地图、事件、进入方式） —— 推迟到走动底座跑通之后。
- **像素风与立绘风的统一**（色板、UI 与场景的视觉衔接） —— 推迟到美术定调阶段。
- **走动时的 UI 策略**（现在全屏面板在走动状态下如何让位） —— 待底座跑通后再定。
- **横竖屏** —— 现有全部 UI 按 1920×1080 横屏设计，走动底座默认沿用横屏。
